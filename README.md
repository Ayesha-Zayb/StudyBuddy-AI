# StudyBuddy AI

## Intelligent Learning Companion

StudyBuddy AI is a modern, browser-based learning platform designed to transform any study topic into an interactive learning experience.

Instead of simply reading notes, learners can generate structured study material, review concepts through interactive flashcards, test their knowledge with quizzes, and monitor their learning activity through a progress dashboard.

## Features

### Smart Study Sessions

Enter a study topic and StudyBuddy AI generates structured learning material containing:

- Topic overview
- Key concepts
- Important points
- Learning guidance

### Interactive Flashcards

Study concepts through interactive 3D flashcards designed around active recall.

Users can:

- Flip cards to reveal answers
- Move to the next card
- Return to the previous card
- Review multiple concepts
- Track cards reviewed

### Knowledge Quizzes

Each supported topic includes an interactive multiple-choice quiz with:

- Instant feedback
- Correct and incorrect answer indicators
- Question progress
- Final percentage score
- Performance feedback
- Quiz retry functionality

### Progress Dashboard

The dashboard tracks:

| Metric | Description |
| --- | --- |
| Study Sessions | Number of study sessions started |
| Quiz Attempts | Number of completed quizzes |
| Average Score | Overall quiz performance |
| Flashcards | Number of flashcards reviewed |

## How It Works

StudyBuddy AI follows a simple active-learning cycle:

**Study Topic**  
↓  
**Generate Study Session**  
↓  
**Review Notes**  
↓  
**Practice With Flashcards**  
↓  
**Complete Quiz**  
↓  
**Receive Instant Feedback**  
↓  
**Review Performance**

## Getting Started

### Requirements

No backend server or special installation is required.

You only need:

- A modern web browser
- VS Code or another code editor

### Run Locally

1. Clone the repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Enter a study topic.
5. Generate your study session.
6. Explore Notes, Flashcards and Quiz.

## Why I Built This

Study tools often separate notes, flashcards and quizzes into different experiences.

StudyBuddy AI was built around a simple idea:

> Learning becomes more effective when studying, recalling and testing knowledge happen in one focused workspace.

The project combines these stages into a single interactive learning experience.
